# Axe rendu

À lire après `SKILL.md`, pour une revue sur cet axe seulement.

- Lis le PDF produit avec LiteParse, pas le source : ces défauts ne se voient
  qu'une fois le document rendu.
- Cherche les défauts suivants : sections vides, listes restées en ligne,
  paragraphe absorbé par la dernière puce, colonnes vides, phrases tronquées,
  balisage visible (`[id]`, `$…$`, `*`).
- Pour chaque défaut, retrouve la ligne source responsable.
