== Blocs

=== Admonitions

TIP: Une bonne pratique ou une piste complémentaire, hors décision.

IMPORTANT: Un point que le décideur ne doit pas manquer.

WARNING: Un risque ou une conséquence coûteuse, difficile à rattraper.

[IMPORTANT]
.Admonition en bloc, avec un titre
====
Une admonition peut contenir plusieurs paragraphes.

* et une liste ;
* sur deux éléments.
====

=== Exemples

.Exemple
====
Un bloc d'exemple, pour un cas concret illustrant la règle qui précède.
====

[%collapsible]
.Bloc repliable (déplié dans le PDF)
====
Dans le HTML, ce bloc est replié ; le PDF l'affiche toujours en entier.
====

[.lead]
Un paragraphe d'introduction mis en avant par le rôle `lead`.

----
# Configuration d'exemple
service:
  nom: portefeuille
  replicas: 3 # <1>
  ressources:

<1> Trois réplicas pour tolérer la perte d'un nœud.
<2> Limite mémoire par conteneur.
