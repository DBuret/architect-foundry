= Décisions d'architecture

[[ADR-01]]
== ADR-01 : Migrer le service portefeuille en deux phases

.Statut
Proposé.

.Contexte
Le volume attendu repose sur xref:hypotheses.adoc#H1[] ; le support éditeur, sur xref:hypotheses.adoc#H2[].

.Décision
Retenir l'option B du xref:chapitre-tables.adoc#tab-couts[tableau des coûts].

.Conséquences
Le financement du second site reste suspendu à xref:points-ouverts.adoc#PO-01[].
